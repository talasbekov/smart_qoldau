# SmartQoldau

Платформа психологической и юридической консультационной помощи: клиент оставляет заявку, система подбирает подходящего верифицированного эксперта, консультация проходит в чате или видео (LiveKit) с шифрованием переписки.

## Возможности

- **Подбор эксперта** — заявка клиента проходит конвейер со скорингом, ротацией офферов и таймаутами (45/20 сек), с эскалацией для срочных случаев.
- **Верификация экспертов** — анкета, загрузка документов, проверка администратором перед допуском к консультациям.
- **Консультации** — атомарное создание сессии из матча, шифрованный чат (AES-256-GCM), видео/аудио через LiveKit с вебхуками участников, эскалация формата, обработка no-show и исходов.
- **Расписание и присутствие** — статусы доступности эксперта в реальном времени (Redis), расписание слотов.
- **Избранное, отзывы и рейтинг** — повторный выбор эксперта клиентом, модерация отзывов.
- **Аудит и WebSocket-события** — журнал действий, realtime-обновления через WS.

## Технологический стек

- **Backend**: NestJS (TypeScript), Prisma ORM, PostgreSQL
- **Realtime**: WebSocket (Socket.io), Redis (presence, таймеры, очереди)
- **Хранилище файлов**: MinIO (S3-совместимое, `@aws-sdk/client-s3`)
- **Видео/аудио**: LiveKit
- **Авторизация**: JWT (`@nestjs/jwt`, `passport-jwt`)
- **Тесты**: Jest (unit + e2e)

## Структура репозитория

```
backend/    Backend-сервис на NestJS (API, WebSocket, бизнес-логика)
infra/      docker-compose для локального окружения (Postgres, Redis, MinIO, LiveKit)
brain/      База знаний проекта: продуктовые решения, бизнес-процессы, планы разработки
docs/       Экспорт UI-прототипа
.github/    CI-workflow'ы
```

## Быстрый старт

```bash
# поднять инфраструктуру (Postgres, Redis, MinIO, LiveKit)
docker compose -f infra/docker-compose.dev.yml up -d

cd backend
npm install
cp .env.example .env   # заполнить переменные окружения

npx prisma migrate dev
npm run start:dev
```

### Тесты

```bash
cd backend
npm run test        # unit
npm run test:e2e    # e2e (требует поднятой инфраструктуры)
```
